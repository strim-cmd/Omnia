# Workflows

## Purpose

Complete engineering process descriptions that define how work moves from start to completion.

## Contents

- One file per process, e.g. ADR Process, RFC Process, Documentation Workflow, Architecture Workflow, Release Workflow.
- Process descriptions only: steps, participants, entry and exit criteria.

## Exclusions

- Executable stage definitions (see pipelines/).
- Prompts and agent role definitions.

## Relationship

Provide the process context for pipelines/; processes reference the standards in ../standards/ and produce artifacts using templates/.
