# Documentation Review Checklist

Evaluate the documentation change against `.ai/standards/DOCUMENTATION.md`. Approve only when the checklist passes.

- [ ] Written in English and Markdown.
- [ ] Clear purpose.
- [ ] Required sections present: Purpose, Scope, Requirements, Non-Goals, Related Documents.
- [ ] YAML front matter with version and status.
- [ ] References the source documents.
- [ ] Does not contradict any existing documentation.
- [ ] Does not invent requirements or capabilities.
- [ ] No placeholders, TODO markers, or lorem ipsum.
- [ ] Concise and production-ready.
