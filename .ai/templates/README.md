# Templates

## Purpose

Reusable document skeletons that define the required structure and front matter of engineering artifacts.

## Contents

- One file per artifact type, e.g. ADR Template, RFC Template, Architecture Template, Issue Template, Module Template.
- Empty skeletons only, with defined sections and metadata fields.

## Exclusions

- Completed or filled-in documents (see examples/).
- Generation and review prompts.

## Relationship

Filled in by generation_prompts/; the resulting artifacts are validated by review_prompts/.
