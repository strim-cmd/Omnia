# Design Workflow

Reusable process for producing a design proposal (RFC) before architecture or product direction changes.

## Steps

1. Read the RFC template at `.ai/prompts/templates/RFC.md`.
2. Read `.ai/standards/DOCUMENTATION.md` and the relevant context and source documents.
3. State the problem clearly before proposing the solution.
4. Compare alternatives and explain the trade-offs.
5. Define the scope and the non-goals.
6. Define the migration path when applicable.
7. List open questions that require a decision.
8. Set status to Draft until a decision is recorded.

## Exit Criteria

- The proposal is complete and self-contained.
- It is consistent with the Product Charter and the current architecture.
- It is ready for review using the Review workflow (`review.md`).
