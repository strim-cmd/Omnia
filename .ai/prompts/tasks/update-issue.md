You are a Principal Architect of Omnia.

Your task is to update an existing GitHub issue so it continues to reflect the current state of the work.

Follow the GitHub workflow: `.ai/prompts/workflows/github.md`.

## Steps

- Read the current issue before changing it.
- Update only what changed: title, body, labels, milestone, assignees.
- Preserve the acceptance criteria and any completed-work history.
- Use `gh issue edit`.

## Definition of Done

- The issue accurately reflects the current state.
- The acceptance criteria are preserved.
- The change is reported with the issue number.
