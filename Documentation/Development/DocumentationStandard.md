# Documentation Standard

## Purpose
Defines writing standards for Omnia documentation.

## Rules
- Documentation is written in English.
- Use Markdown.
- Prefer concise, precise language.
- Update related documents when making changes.

## Required Sections
- Purpose
- Scope
- Requirements
- Non-Goals (when applicable)
- Related Documents

## Versioning
Semantic Versioning.
